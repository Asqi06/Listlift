# ListLift M0 + M1 Implementation Plan

> **For agentic workers:** Implementing M0 (Foundation) and M1 (First Public Tools + Rules Engine + Hono API) milestone-by-milestone per `docs/PRD.md`.

**Goal:** Build the ListLift pnpm monorepo with Astro static pages, Preact interactive islands, Hono Cloudflare Worker API, D1/R2 configuration, "calm premium" design system, versioned marketplace skills engine, and the M1 public tools (Character Counter, Title Generator + Checker, SKU Generator, Listing Score Linter).

**Architecture:** pnpm workspace monorepo (`/apps/web`, `/packages/core`, `/packages/skills`, `/packages/ui`, `/docs`). Marketplace rules live strictly in `/packages/skills` as validated JSON + markdown prompts. Validation, scoring, and SKU/title utilities live in `/packages/core` with strict TypeScript + Zod. `/apps/web` serves static Astro HTML with Preact islands for interactive tools and a Hono Worker for `/api/v1/*`.

**Tech Stack:** pnpm, TypeScript (strict), Astro 5, Preact, Hono, Zod, Vitest, Cloudflare Workers (`wrangler.jsonc`, D1, R2).

**Spec:** `docs/PRD.md`

## Global Constraints

- TypeScript strict mode everywhere; Zod for all external input; no `any` without comment.
- Never commit secrets; use `.dev.vars` + `.env.example`.
- Marketplace rules live only in `packages/skills`; generation/validation code reads them, never hard-codes limits.
- Public pages are static; add islands only where interaction is needed (< 60 KB gzip JS budget).
- WCAG 2.2 AA contrast, 44x44 px touch targets, full keyboard support, `prefers-reduced-motion` respected.
- Non-affiliation disclaimer in footer; text names only, no marketplace logos.
- No paid dependencies added.

## Review Focus

1. Empty, whitespace-only, or emoji/multi-byte Unicode input in Character Counter / Title Checker (e.g. Hindi/Devanagari or emojis affecting char vs byte counts like Amazon's 250-byte search terms).
2. Banned/prohibited claims (medical, "guaranteed #1", counterfeit-adjacent words) caught by the Listing Score linter.
3. Duplicate SKU detection in batch mode and sanitization of special characters in brand/category inputs.
4. Invalid or unknown marketplace slugs passed to `/api/v1/*` returning clean Zod 400 errors (never 500s).
5. Theme toggle cookie persistence and command palette (`Ctrl/Cmd+K`) keyboard navigation + Escape close without trapping focus.
